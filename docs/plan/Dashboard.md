## 2. 当前产品目标

CodeWorkspace 面向多仓环境切换，首版补偿能力必须防止一次失败静默留下未知的部分状态。目标用户是通过 `codews switch` 编排多个 Git 仓库的开发者和自动化脚本。

**本次聚焦**：恢复新克隆目录及已有仓库的分支、游离提交和 HEAD，并稳定报告补偿结果。持久化事务日志和 Hook 专用逆操作协议暂缓。
